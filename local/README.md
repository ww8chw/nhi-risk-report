# 安安診所 · 健檢風險評估報告（本地離線版）

完全本地端跑，自動透過國健署「科學算病館」算 5 種慢性病 10 年風險。

## 需要的東西

- 一台 Mac 或 Windows 電腦
- 網路連線（程式只連國健署 cdrc.hpa.gov.tw）
- 一次性安裝 [Bun](https://bun.sh)（10MB，腳本會自動裝）

## 使用方式

### 第一次

**Mac**：
1. 把整個 `local/` 資料夾複製到電腦上想放的地方（例如桌面）
2. 雙擊 `啟動.command`
3. 第一次會跳「無法開啟」→ 到「系統設定 → 隱私權與安全性」按「仍要打開」
4. 終端機視窗會自動安裝 Bun（約 30 秒）→ 啟動代理 → 開瀏覽器

**Windows**：
1. 把 `local/` 資料夾複製到電腦
2. 雙擊 `啟動.bat`
3. 第一次會自動下載 Bun

### 之後每次

雙擊 `啟動.command` (Mac) 或 `啟動.bat` (Windows)，瀏覽器會自動開 `report.html`。

填表 → 按「產生報告」→ 自動算分 → 列印或存 PDF。

### 結束

關閉終端機視窗即停止伺服器。

## 為什麼要本地跑

國健署 API（cdrc.hpa.gov.tw）對非台灣 IP 在 TCP 層拒絕連線。部署到海外雲端 server (Railway us-west2 等) 都是 `UND_ERR_CONNECT_TIMEOUT`。從台灣本地跑沒問題。

## 檔案說明

```
local/
├── 啟動.command    # Mac 雙擊啟動腳本
├── 啟動.bat        # Windows 雙擊啟動腳本
├── proxy.ts        # Bun 寫的本地代理（port 7777）
├── report.html     # 單檔 SPA — 全部 UI 都在這裡
└── README.md       # 本檔
```

`report.html` 直接打開也能看到 UI，但「產生報告」需要代理在跑（會有狀態提示）。

## 疑難排解

**「啟動.command」無法執行 / 顯示「未驗證的開發者」**
- 系統設定 → 隱私權與安全性 → 滑到底有「仍要打開」按鈕

**Port 7777 已被佔用**
- 之前的代理沒關乾淨。重啟電腦最簡單。

**「無法連到本地代理」紅字**
- 確認終端機視窗還開著、有看到「✓ 代理運作中」
- 沒看到的話重新雙擊 `啟動.command`

**算出來所有疾病都「請求逾時」**
- 確認電腦能上網
- 確認沒掛 VPN（VPN 出口若是海外 IP 會被擋）

## 隱私

所有病人資料只在你的電腦記憶體與瀏覽器 session 中。
程式不存任何資料到硬碟、不送任何資料到第三方（除了把計算用的數值送到國健署官方 API）。
關閉視窗後資料即消失。
